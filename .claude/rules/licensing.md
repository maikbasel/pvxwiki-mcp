# Licensing and attribution

Always loaded. PvX wiki text is licensed CC BY-NC-SA 2.5 Unported. Serving it without attribution,
or commercially, breaks the licence.

Source: `PvXwiki:Copyrights` and the API's `siteinfo` rightsinfo, both checked 2026-10-09.

## Required

- Every tool response that contains wiki content includes, per build: page title, canonical page URL,
  the revision ID it was copied from, credit to "PvX wiki contributors", and the licence name and URL.
- Pin the licence as named consts: name "CC BY-NC-SA 2.5", URL
  `https://creativecommons.org/licenses/by-nc-sa/2.5/`. If `PvXwiki:Copyrights` changes, update both
  and this file.
- NonCommercial: no ads, no paid access, no paid tier for the server or the data.
- Share-alike: content derived from the wiki (parsed fields, summaries, search indexes that are
  served) stays under the same licence. The project's own source code licence is separate.
- The README credits the PvX wiki and states the content licence.

## Forbidden

- Implying affiliation with or endorsement by ArenaNet, NCSOFT, Fandom, or the PvX wiki. Naming them
  factually ("Guild Wars is a trademark of ArenaNet") is fine. Their logos and branding are not.
- Stripping or shortening the attribution to save tokens.
