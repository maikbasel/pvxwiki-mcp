# Parser Crate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `pvxwiki-parser` library crate whose `parse(&str) -> ParsedPage` turns one PvX build page's wikitext into sections, vetting data and skill bars, losing no bytes and never panicking.

**Architecture:** The repo becomes a Cargo workspace (`crates/parser`, `crates/pvxwiki-mcp`). `parse-wiki-text-2` gives the generic wikitext tree (headings, templates, tags, with byte offsets); a hand-written scanner handles PvXCode's `[build]` tag, which is not wikitext. Profession and attribute names resolve through lookup tables ported verbatim from the PvXCode extension.

**Tech Stack:** Rust 1.96, edition 2024. `parse-wiki-text-2` 0.2.0 (MIT-0), `tracing` 0.1. `insta` 1.x for snapshot tests (dev only).

**Spec:** `docs/superpowers/specs/2026-10-09-parser-design.md`

## Global Constraints

- Edition 2024, `rust-version = "1.96"`, crate licence MIT, `publish = false`.
- Lints inherited from the workspace: `unsafe_code = "forbid"`; clippy `unwrap_used`, `expect_used`, `todo`, `print_stdout`, `print_stderr` denied (tests may unwrap: `clippy.toml`).
- The parser does no I/O. It logs through `tracing` per `.claude/rules/logging.md` (no subscriber, structured fields, constant messages, outside text logged with `?` and capped). Runtime dependencies: `parse-wiki-text-2`, `tracing`.
- `parse` never panics. Never index a `&str` with a byte offset that did not come from the parse tree or from a `find` on the same string; use `str::get` where in doubt.
- Missing values are `None`, never a default. Strings from the page are kept as written unless the spec names a normalisation.
- No `TODO`/`FIXME`. No speculative abstractions.
- Tests never call the wiki. Fixtures are recorded manually (Task 1 and Task 7 say how).
- Commits: `CLAUDE.md` says do not commit unless the user asks. Each task ends with a commit step; run it only if the user has said to commit, otherwise stage with `git add` and move on. Commit messages: conventional with scope, e.g. `feat(parser): ...`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Definition of done per task: `cargo test`, `cargo clippy --all-targets -- -D warnings`, `cargo build` pass. A virtual workspace runs these over all members; no `--workspace` flag needed.

## Review Focus

1. Non-ASCII text (umlauts, curly quotes, a leading BOM) next to headings and `[build]` tags: offsets must stay on char boundaries; parse must not panic. Test: Task 7 no-panic list.
2. A `[build]` cut off mid-tag (no `]` or no `[/build]`), e.g. a half-saved edit: `UnclosedBuildTag` issue, every other section and bar still parsed. Test: Task 3 `find` tests and Task 6 `unclosed_build_tag_is_an_issue_and_the_rest_still_parses`.
3. Two vetting tags on one page (`{{build-stub}}` left above `{{Real-Vetting}}`): first tag wins, `MultipleVettingTags` recorded. Test: Task 5.
4. A page with no headings, or headings only: one summary section (possibly empty), output still lossless. Test: Task 4 sections tests.
5. Template name spelling (`Real-Vetting ` with trailing space, `real-vetting`, `Build-stub`, and the unrelated `{{section-stub}}`): spelling variants match, `section-stub` does not. Test: Task 5.

/// One parsed build page. Title, revision ID and categories come from the API, not from here.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ParsedPage {
    pub vetting: Vetting,
    /// Page order. Index 0 is the summary before the first heading (heading `None`, level 0),
    /// present even when empty. Concatenating every `wikitext` gives back the input exactly.
    pub sections: Vec<Section>,
    /// Every `[build]` tag inside `<pvxbig>`, in page order.
    pub skill_bars: Vec<SkillBar>,
    pub issues: Vec<ParseIssue>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Vetting {
    Vetted(Vetted),
    /// `{{build-stub}}`: the build is still being written.
    Stub,
    /// No vetting tag on the page.
    Missing,
}

/// From `{{Real-Vetting}}`.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Vetted {
    pub rating: Option<Rating>,
    pub status: Option<Status>,
    /// Positional arguments as written, empty ones skipped: "farming", "RA", "PvE team".
    pub gameplay_types: Vec<String>,
    /// Set when the tag has any of `date`, `category`, `reasonN`.
    pub archive: Option<Archive>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Rating {
    Great,
    Good,
    Creative,
    Trash,
    Abandoned,
    Testing,
    Trial,
    Archived,
    Unknown(String),
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Status {
    Meta,
    Provisional,
    Unknown(String),
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Archive {
    pub date: Option<String>,
    pub category: Option<String>,
    /// `reason1`..`reasonN` in number order.
    pub reasons: Vec<String>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Section {
    /// Heading text, trimmed. `None` for the summary.
    pub heading: Option<String>,
    /// 0 for the summary, else the heading level (2 for `==`).
    pub level: u8,
    /// Exact source slice, heading line included.
    pub wikitext: String,
    /// Markup stripped and whitespace collapsed. For the search index only.
    pub text: String,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SkillBar {
    /// Index into `ParsedPage::sections`.
    pub section: usize,
    /// Exact `[build ...]...[/build]` source.
    pub raw: String,
    /// `name="..."` from the tag header.
    pub name: Option<String>,
    /// Set when the bar is inside `{{Variantbar}}`.
    pub variant: Option<Variant>,
    pub primary: Option<Profession>,
    /// `None` for "any", for a missing secondary, and when equal to the primary.
    pub secondary: Option<Profession>,
    /// The `prof=` value as written.
    pub professions_raw: Option<String>,
    pub attributes: Vec<Attribute>,
    pub slots: Vec<Slot>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Variant {
    pub name: Option<String>,
    /// Team slot this variant replaces (`position=`), as written.
    pub position: Option<String>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum Profession {
    Warrior,
    Ranger,
    Monk,
    Necromancer,
    Mesmer,
    Elementalist,
    Assassin,
    Ritualist,
    Paragon,
    Dervish,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Attribute {
    /// Canonical name as the wiki renders it ("Shadow Arts"); `None` if the name matched nothing.
    pub name: Option<String>,
    /// Name as written ("sha").
    pub raw_name: String,
    /// Value as written ("12+1+3").
    pub value: String,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Slot {
    /// `name` is the text before `@`, `|` or `:`, trimmed, page casing. `raw` is the whole
    /// bracketed slot. Abbreviations are not expanded.
    Skill { name: String, raw: String },
    /// `[Optional]`: an open slot.
    Optional,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ParseIssue {
    /// Index into `ParsedPage::sections`, when the problem has a location.
    pub section: Option<usize>,
    /// Byte offset into the page where the problem starts, when it has a location.
    pub offset: Option<usize>,
    pub kind: IssueKind,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum IssueKind {
    /// A `[build ` inside `<pvxbig>` without a closing `]` or `[/build]`.
    UnclosedBuildTag,
    /// A `prof=` part that matched no profession and is not "any".
    UnknownProfession(String),
    /// An `attribute=value` pair whose name matched no attribute.
    UnknownAttribute(String),
    /// More than one `{{Real-Vetting}}` / `{{build-stub}}`; the first one is used.
    MultipleVettingTags,
    /// The wikitext parser hit `PARSE_TIMEOUT`; output is built from the partial tree.
    TimedOut,
}
```

//! Profession and attribute names, ported from the PvXCode extension
//! (github.com/Wikia/pvxcode, gwbbcode/gwbbcode.inc.php at commit afe42e3: `gws_prof_name`,

use crate::Profession;

/// The first entry the lowercased input is a prefix of wins.

pub(crate) fn profession(input: &str) -> Option<Profession> {
    let input = input.trim().to_lowercase();
    if input.is_empty() {
        return None;
    }
    // PvXCode special case: "rt" is the only abbreviation that is not a prefix of the name.
    if input == "rt" {
        return Some(Profession::Ritualist);
    }
    PROFESSIONS
        .iter()
        .find(|(name, _)| name.starts_with(&input))
        .map(|&(_, profession)| profession)
}

pub(crate) fn attribute(input: &str) -> Option<&'static str> {
    let key = input.replace('_', "").to_lowercase();
    if key.is_empty() {
        return None;
    }
    ATTRIBUTES
        .iter()
        .find(|(long, _)| long.starts_with(&key))
        .map(|&(_, name)| name)
}

//! PvXCode's `[build]` tag, which is not wikitext: `[build <header>][slot]...[/build]`.
//!
//! Grammar from github.com/Wikia/pvxcode, gwbbcode/gwbbcode.inc.php at commit afe42e3:
//! `build_replace` (`\[build ([^\]]*)\](.*?)\[/build\]`, case-insensitive),
//! `gws_build_profession`, `gws_attributes_clean`, `attribute_list_raw`, `skill_name_replace`.

use std::ops::Range;

use crate::lookup;
use crate::{Attribute, IssueKind, Profession, Slot};

const OPEN: &str = "[build ";
const CLOSE: &str = "[/build]";

#[derive(Debug, PartialEq, Eq)]
pub(crate) enum Found {
    Closed(Range<usize>),
    /// Byte offset of a `[build ` with no header `]` or no `[/build]` after it.
    Unclosed(usize),
}

pub(crate) struct Bar {
    pub name: Option<String>,
    pub professions_raw: Option<String>,
    pub primary: Option<Profession>,
    pub secondary: Option<Profession>,
    pub attributes: Vec<Attribute>,
    pub slots: Vec<Slot>,
    pub issues: Vec<IssueKind>,
}

/// Finds bars in `text`. Stops at the first unclosed one, as the rest of `text` cannot be
/// split into bars reliably.
pub(crate) fn find(text: &str) -> Vec<Found> {
    // ASCII lowercasing keeps every byte offset valid in `text`.
    let lower = text.to_ascii_lowercase();
    let mut found = Vec::new();
    let mut pos = 0;
    while let Some(at) = lower[pos..].find(OPEN) {
        let start = pos + at;
        let Some(header_len) = lower[start..].find(']') else {
            found.push(Found::Unclosed(start));
            break;
        };
        let header_end = start + header_len;
        match lower[header_end..].find(CLOSE) {
            Some(close) => {
                let end = header_end + close + CLOSE.len();
                found.push(Found::Closed(start..end));
                pos = end;
            }
            None => {
                found.push(Found::Unclosed(start));
                break;
            }
        }
    }
    found
}

/// Parses one bar. `raw` starts with `[build ` (any case) and ends with `[/build]`.
pub(crate) fn parse(raw: &str) -> Bar {
    let header_end = raw.find(']').unwrap_or(raw.len());
    let header = raw.get(OPEN.len()..header_end).unwrap_or("");
    let body = raw
        .get(header_end + 1..raw.len().saturating_sub(CLOSE.len()))
        .unwrap_or("");

    let mut issues = Vec::new();
    let mut rest = header.to_string();
    let name = take_quoted(&mut rest, "name");
    take_quoted(&mut rest, "desc");
    let professions_raw = take_prof(&mut rest);

    let (primary, secondary) = match professions_raw.as_deref() {
        Some(value) => professions(value, &mut issues),
        None => (None, None),
    };

    let attributes = rest
        .split_whitespace()
        .filter_map(|token| {
            let (raw_name, value) = token.split_once('=')?;
            if value.contains('=') {
                return None;
            }
            let name = lookup::attribute(raw_name);
            if name.is_none() {
                issues.push(IssueKind::UnknownAttribute(raw_name.to_string()));
            }
            Some(Attribute {
                name: name.map(str::to_string),
                raw_name: raw_name.to_string(),
                value: value.to_string(),
            })
        })
        .collect();

    Bar { name, professions_raw, primary, secondary, attributes, slots: slots(body), issues }
}

/// Removes `key="value"` (value non-empty) from `header` and returns the value.
fn take_quoted(header: &mut String, key: &str) -> Option<String> {
    let marker = format!("{key}=\"");
    let start = header.find(&marker)?;
    let value_start = start + marker.len();
    let value_len = header[value_start..].find('"')?;
    if value_len == 0 {
        return None;
    }
    let value = header[value_start..value_start + value_len].to_string();
    header.replace_range(start..value_start + value_len + 1, " ");
    Some(value)
}

/// Removes `prof=<value>` from `header` and returns the value (`[^ \]]*` in PvXCode).
fn take_prof(header: &mut String) -> Option<String> {
    let start = header.find("prof=")?;
    let value_start = start + "prof=".len();
    let value_end = header[value_start..]
        .find(char::is_whitespace)
        .map_or(header.len(), |len| value_start + len);
    let value = header[value_start..value_end].to_string();
    header.replace_range(start..value_end, " ");
    (!value.is_empty()).then_some(value)
}

fn professions(value: &str, issues: &mut Vec<IssueKind>) -> (Option<Profession>, Option<Profession>) {
    let (primary_raw, secondary_raw) = match value.split_once('/') {
        Some((p, s)) if !p.is_empty() && !s.is_empty() => (p, Some(s)),
        Some((p, _)) => (p, None),
        None => (value, None),
    };
    let mut resolve = |raw: &str| {
        let found = lookup::profession(raw);
        if found.is_none() && !raw.is_empty() && !raw.eq_ignore_ascii_case("any") {
            issues.push(IssueKind::UnknownProfession(raw.to_string()));
        }
        found
    };
    let primary = resolve(primary_raw);
    let secondary = secondary_raw.and_then(&mut resolve).filter(|s| Some(*s) != primary);
    (primary, secondary)
}

/// `[Name]`, `[Name@12]`, `[Name|shown]`, `[[Name]` (no icon), `[Optional]`. Text between
/// slots is ignored.
fn slots(body: &str) -> Vec<Slot> {
    let mut slots = Vec::new();
    let mut rest = body;
    while let Some(open) = rest.find('[') {
        let after = &rest[open + 1..];
        let Some(close) = after.find(']') else { break };
        let raw = &rest[open..open + 1 + close + 1];
        let inner = after[..close].trim_start_matches('[').trim();
        rest = &after[close + 1..];
        if inner.eq_ignore_ascii_case("optional") {
            slots.push(Slot::Optional);
            continue;
        }
        let name = inner.split(['@', '|', ':']).next().unwrap_or("").trim();
        if !name.is_empty() {
            slots.push(Slot::Skill { name: name.to_string(), raw: raw.to_string() });
        }
    }
    slots
}
```

/// Text for the search index: text nodes, link labels and template parameter values, with
/// markup dropped and whitespace collapsed to single spaces.
pub(crate) fn plain_text(nodes: &[Node]) -> String {

fn push_text(nodes: &[Node], out: &mut String) {
    for node in nodes {
        match node {
            Node::Text { value, .. } => out.push_str(value),
            Node::CharacterEntity { character, .. } => out.push(*character),
            Node::Link { target, text, .. } => {
                if text.is_empty() {
                    out.push_str(target);
                } else {
                    push_text(text, out);
                }
            }
            Node::ExternalLink { nodes, .. } | Node::Preformatted { nodes, .. } => {
                push_text(nodes, out)
            }
            Node::Heading { nodes, .. } | Node::Tag { nodes, .. } => {
                out.push(' ');
                push_text(nodes, out);
                out.push(' ');
            }
            Node::Image { text, .. } => push_text(text, out),
            Node::Template { parameters, .. } => {
                for parameter in parameters {
                    out.push(' ');
                    push_text(&parameter.value, out);
                }
                out.push(' ');
            }
            Node::UnorderedList { items, .. } | Node::OrderedList { items, .. } => {
                for item in items {
                    out.push(' ');
                    push_text(&item.nodes, out);
                }
                out.push(' ');
            }
            Node::DefinitionList { items, .. } => {
                for item in items {
                    out.push(' ');
                    push_text(&item.nodes, out);
                }
                out.push(' ');
            }
            Node::Table { captions, rows, .. } => {
                for caption in captions {
                    out.push(' ');
                    push_text(&caption.content, out);
                }
                for row in rows {
                    for cell in &row.cells {
                        out.push(' ');
                        push_text(&cell.content, out);
                    }
                }
                out.push(' ');
            }
            Node::ParagraphBreak { .. }
            | Node::StartTag { .. }
            | Node::EndTag { .. }
            | Node::HorizontalDivider { .. } => out.push(' '),
            Node::Redirect { target, .. } => out.push_str(target),
            Node::Bold { .. }
            | Node::BoldItalic { .. }
            | Node::Italic { .. }
            | Node::Category { .. }
            | Node::Comment { .. }
            | Node::MagicWord { .. }
            | Node::Parameter { .. } => {}
        }
    }

//! Splits the page at top-level headings. Sections are contiguous byte ranges of the input, so
//! concatenating their wikitext gives back the input exactly.

use parse_wiki_text_2::Node;

use crate::Section;
use crate::wikitext::plain_text;

/// Returns the sections and the start byte offset of each.
pub(crate) fn split(src: &str, nodes: &[Node]) -> (Vec<Section>, Vec<usize>) {
    struct Draft {
        heading: Option<String>,
        level: u8,
        start: usize,
        text: String,
    }
    let mut drafts = vec![Draft { heading: None, level: 0, start: 0, text: String::new() }];
    for node in nodes {
        if let Node::Heading { start, level, nodes: title, .. } = node {
            drafts.push(Draft {
                heading: Some(plain_text(title)),
                level: *level,
                start: *start,
                text: String::new(),
            });
        }
        if let Some(draft) = drafts.last_mut() {
            draft.text.push(' ');
            draft.text.push_str(&plain_text(std::slice::from_ref(node)));
        }
    }

    let starts: Vec<usize> = drafts.iter().map(|d| d.start).collect();
    let sections = drafts
        .into_iter()
        .enumerate()
        .map(|(i, draft)| {
            let end = starts.get(i + 1).copied().unwrap_or(src.len());
            Section {
                heading: draft.heading,
                level: draft.level,
                wikitext: src.get(draft.start..end).unwrap_or("").to_string(),
                text: draft.text.split_whitespace().collect::<Vec<_>>().join(" "),
            }
        })
        .collect();
    (sections, starts)
}

/// Index of the section containing byte `offset`. `starts[0]` is 0.
pub(crate) fn index_at(starts: &[usize], offset: usize) -> usize {
    starts.partition_point(|&start| start <= offset).saturating_sub(1)
}

use std::time::Duration;

use parse_wiki_text_2::ParseError;

/// Upper bound for the wikitext tree parse of one page. Real pages take well under 10 ms.
const PARSE_TIMEOUT: Duration = Duration::from_secs(5);

/// Longest piece of page text put into a log event.
const SNIPPET_MAX_CHARS: usize = 80;

/// Parses one build page. Never fails: problems are listed in `ParsedPage::issues`.
#[tracing::instrument(level = "debug", skip_all, fields(bytes = wikitext.len()))]
pub fn parse(wikitext: &str) -> ParsedPage {
    let (output, timed_out) = match wikitext::configuration().parse_with_timeout(wikitext, PARSE_TIMEOUT) {
        Ok(output) => (output, false),
        Err(ParseError::TimedOut { output, .. }) => (output, true),
    };
    for warning in &output.warnings {
        tracing::trace!(
            start = warning.start,
            end = warning.end,
            message = warning.message.message(),
            "wikitext warning"
        );
    }
    let mut issues = Vec::new();
    if timed_out {
        issues.push(ParseIssue { section: None, offset: None, kind: IssueKind::TimedOut });
    }
    let (sections, _starts) = sections::split(wikitext, &output.nodes);
    let page = ParsedPage { vetting: Vetting::Missing, sections, skill_bars: Vec::new(), issues };
    log_outcome(wikitext, &page);
    page
}

/// One `debug` event per issue (issues are returned as data; the caller decides on `warn`),
/// then one summary.
fn log_outcome(src: &str, page: &ParsedPage) {
    for issue in &page.issues {
        tracing::debug!(
            section = issue.section,
            offset = issue.offset,
            kind = ?issue.kind,
            snippet = ?issue.offset.map(|offset| snippet(src, offset)),
            "page parse issue"
        );
    }
    tracing::debug!(
        sections = page.sections.len(),
        skill_bars = page.skill_bars.len(),
        issues = page.issues.len(),
        "page parsed"
    );
}

/// Up to `SNIPPET_MAX_CHARS` characters of `src` from byte `offset`; empty if `offset` is not
/// a char boundary inside `src`.
fn snippet(src: &str, offset: usize) -> &str {
    let Some(rest) = src.get(offset..) else { return "" };
    let end = rest.char_indices().nth(SNIPPET_MAX_CHARS).map_or(rest.len(), |(i, _)| i);
    &rest[..end]
}

pub(crate) struct TemplateRef<'n, 'a> {
    /// Normalised with `template_name`.
    pub name: String,
    pub start: usize,
    pub end: usize,
    pub parameters: &'n [Parameter<'a>],
}

pub(crate) struct Collected<'n, 'a> {
    /// Every template in the tree, in document order.
    pub templates: Vec<TemplateRef<'n, 'a>>,
    /// Byte ranges of every `<pvxbig>` element, tags included, outermost only, in order.
    pub pvxbig: Vec<(usize, usize)>,
}

pub(crate) fn collect<'n, 'a>(nodes: &'n [Node<'a>]) -> Collected<'n, 'a> {
    let mut collected = Collected { templates: Vec::new(), pvxbig: Vec::new() };
    walk(nodes, &mut collected);
    collected.pvxbig.sort_unstable();
    let mut outermost: Vec<(usize, usize)> = Vec::new();
    for range in collected.pvxbig {
        if outermost.last().is_none_or(|last| range.0 >= last.1) {
            outermost.push(range);
        }
    }
    collected.pvxbig = outermost;
    collected
}

fn walk<'n, 'a>(nodes: &'n [Node<'a>], acc: &mut Collected<'n, 'a>) {
    for node in nodes {
        match node {
            Node::Template { name, parameters, start, end } => {
                acc.templates.push(TemplateRef {
                    name: template_name(name),
                    start: *start,
                    end: *end,
                    parameters,
                });
                for parameter in parameters {
                    walk(&parameter.value, acc);
                }
            }
            Node::Tag { name, nodes, start, end } => {
                if name.eq_ignore_ascii_case("pvxbig") {
                    acc.pvxbig.push((*start, *end));
                }
                walk(nodes, acc);
            }
            Node::Heading { nodes, .. }
            | Node::ExternalLink { nodes, .. }
            | Node::Preformatted { nodes, .. } => walk(nodes, acc),
            Node::Link { text, .. } | Node::Image { text, .. } => walk(text, acc),
            Node::UnorderedList { items, .. } | Node::OrderedList { items, .. } => {
                for item in items {
                    walk(&item.nodes, acc);
                }
            }
            Node::DefinitionList { items, .. } => {
                for item in items {
                    walk(&item.nodes, acc);
                }
            }
            Node::Table { rows, .. } => {
                for row in rows {
                    for cell in &row.cells {
                        walk(&cell.content, acc);
                    }
                }
            }
            _ => {}
        }
    }
}

/// MediaWiki treats `_` and space alike in names; case is normalised fully here because no two
/// PvX templates differ only by case.
pub(crate) fn template_name(name: &[Node]) -> String {
    plain_text(name).replace('_', " ").to_lowercase()
}

/// Lowercased, trimmed name of a named parameter; `None` for positional ones.
pub(crate) fn param_name(src: &str, parameter: &Parameter) -> Option<String> {
    parameter.name.as_ref()?;
    let raw = src.get(parameter.start..parameter.end)?;
    raw.split_once('=').map(|(name, _)| name.trim().to_lowercase())
}

/// Trimmed source text of a parameter's value.
pub(crate) fn param_value<'s>(src: &'s str, parameter: &Parameter) -> &'s str {
    let raw = src.get(parameter.start..parameter.end).unwrap_or("");
    let value = if parameter.name.is_some() {
        raw.split_once('=').map_or("", |(_, value)| value)
    } else {
        raw
    };
    value.trim()
}

/// Value of the named parameter `key`, if present and non-empty.
pub(crate) fn named(src: &str, parameters: &[Parameter], key: &str) -> Option<String> {
    parameters
        .iter()
        .find(|p| param_name(src, p).as_deref() == Some(key))
        .map(|p| param_value(src, p))
        .filter(|value| !value.is_empty())
        .map(str::to_string)
}

/// The first vetting tag wins. The second value is the byte offset of a second one, if any.
pub(crate) fn extract(src: &str, templates: &[TemplateRef]) -> (Vetting, Option<usize>) {
    let mut tags = templates
        .iter()
        .filter(|t| t.name == REAL_VETTING || t.name == BUILD_STUB);
    let Some(first) = tags.next() else {

    };

    if first.name == BUILD_STUB {
        return (Vetting::Stub, duplicate);
    }
    (Vetting::Vetted(vetted(src, first.parameters)), duplicate)
}

fn vetted(src: &str, parameters: &[Parameter]) -> Vetted {
    let mut vetted = Vetted { rating: None, status: None, gameplay_types: Vec::new(), archive: None };
    let mut date = None;
    let mut category = None;
    let mut reasons: Vec<(u32, String)> = Vec::new();
    for parameter in parameters {
        let value = param_value(src, parameter);
        if value.is_empty() {
            continue;
        }
        match param_name(src, parameter).as_deref() {
            None => vetted.gameplay_types.push(value.to_string()),
            Some("rating") => vetted.rating = Some(rating(value)),
            Some("status") => vetted.status = Some(status(value)),
            Some("date") => date = Some(value.to_string()),
            Some("category") => category = Some(value.to_string()),
            Some(other) => {
                if let Some(n) = other.strip_prefix("reason").and_then(|n| n.parse().ok()) {
                    reasons.push((n, value.to_string()));
                }
            }
        }
    }
    reasons.sort_by_key(|(n, _)| *n);
    if date.is_some() || category.is_some() || !reasons.is_empty() {
        vetted.archive = Some(Archive {
            date,
            category,
            reasons: reasons.into_iter().map(|(_, reason)| reason).collect(),
        });
    }
    vetted
}

                    section: Some(sections::index_at(&starts, start + at)),
                    offset: Some(start + at),
                    kind: IssueKind::UnclosedBuildTag,
                }),
            }
        }
    }
    let page = ParsedPage { vetting, sections, skill_bars, issues };
    log_outcome(wikitext, &page);
    page
}

/// The `{{Variantbar}}` (Template:Variantbar, rev 1285529) whose source contains `offset`.
fn variant_at(src: &str, templates: &[wikitext::TemplateRef], offset: usize) -> Option<Variant> {
    templates
        .iter()
        .find(|t| t.name == "variantbar" && t.start < offset && offset < t.end)
        .map(|t| Variant {
            name: wikitext::named(src, t.parameters, "name"),
            position: wikitext::named(src, t.parameters, "position"),
        })
}

//! Malformed and hostile input never panics and never loses bytes.

use pvxwiki_parser::{IssueKind, parse};

const INPUTS: &[&str] = &[
    "",
    "== only ==",
    "== a ==\n== b ==\n",
    "{{",
    "[[",
    "}}]]",
    "<pvxbig>",
    "<pvxbig>[build prof=A/E",
    "<pvxbig>[build prof=A/E sha=12][Dash]</pvxbig>",
    "<pvxbig>[build ][/build]</pvxbig>",
    "<pvxbig>[build prof=/][[][/build]</pvxbig>",
    "{{Real-Vetting|rating=",
    "{{Real-Vetting|=|==|reason99999999999999999999=x}}",
    "{{Variantbar|template=<pvxbig>[build prof=A][x][/build]</pvxbig>}}",
    "\u{feff}== Über ==\nümlaut ’quotes’ <pvxbig>[build prof=Ä/É ü=12][Ünknown][/build]</pvxbig>",
    "<pvxbig><pvxbig>[build prof=A][Dash][/build]</pvxbig></pvxbig>",
];

#[test]
fn malformed_input_parses_without_panic_and_stays_lossless() {
    for input in INPUTS {
        let page = parse(input);
        let joined: String = page.sections.iter().map(|s| s.wikitext.as_str()).collect();
        assert_eq!(&joined, input, "{input:?}");
    }
}

#[test]
fn unclosed_bar_in_pvxbig_is_reported() {
    let page = parse("<pvxbig>[build prof=A/E sha=12][Dash]</pvxbig>");
    assert!(page.issues.iter().any(|i| i.kind == IssueKind::UnclosedBuildTag));
    assert!(page.skill_bars.is_empty());
}

#[test]
fn nested_pvxbig_yields_each_bar_once() {
    let page = parse("<pvxbig><pvxbig>[build prof=A][Dash][/build]</pvxbig></pvxbig>");
    assert_eq!(page.skill_bars.len(), 1);
}

#[test]
fn very_long_page_parses() {
    let section = "== Usage ==\n* [[gww:Dash|Dash]] {{skill pvxicon|Dash}} text\n";
    let input = section.repeat(5_000);
    let page = parse(&input);
    assert_eq!(page.sections.len(), 5_001);
}
